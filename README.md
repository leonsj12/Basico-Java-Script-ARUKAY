# JavaScript – Módulo Básico (Arukay)

**Descripción general**

Este repositorio documenta mi proceso de aprendizaje del Módulo Básico de JavaScript del programa de Arukay.

El módulo está compuesto por 15 sesiones progresivas en las que desarrollo habilidades fundamentales en programación, lógica computacional y construcción de programas utilizando JavaScript.

A lo largo del curso trabajo desde la configuración del entorno de desarrollo hasta la creación de pequeños programas funcionales aplicados a situaciones reales.


 **Objetivo del módulo**

El propósito de este módulo es:

- Comprender los fundamentos de JavaScript.
- Configurar y utilizar un entorno de desarrollo.
- Escribir y ejecutar código correctamente.
- Aplicar la lógica de programación en ejercicios prácticos.
- Desarrollar una base sólida para temas más avanzados.

# Sesión 1 – Introducción a JavaScript

Duración: 1 hora 20 minutos  
Nivel: Uno  

## Descripción

En esta primera sesión inicié mi camino en JavaScript aprendiendo a configurar el entorno de desarrollo y a utilizar un editor de código para escribir y ejecutar programas.

## Objetivos de la sesión

Al finalizar esta sesión fui capaz de:

- Manipular el entorno de desarrollo.
- Escribir y ejecutar código JavaScript.
- Utilizar herramientas en la nube.
- Aplicar ejemplos prácticos como mostrar datos personales en consola.

## Temas trabajados

- Configuración del entorno.
- Uso del editor de código.
- Escritura de código básico.
- Impresión de mensajes con `console.log()`.
